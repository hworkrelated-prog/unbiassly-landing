# Unbiassly, Inc.

Public landing page for [unbiassly.com](https://unbiassly.com).

Unbiassly, Inc. is a US-based company. This site explains its ventures:

- **SaaS:** [TskFlow](https://tskflow.com), [tskflow.com/unbiassly](https://tskflow.com/unbiassly), and [SellDispatch](https://selldispatch.com)
- **US truck dispatching:** [TomaFreight](https://tomafreight.com)
- **Founder:** [Hashim Mahmood](https://hashimmahmood.com)

The site is a single self-contained `index.html`, hosted as a free Render static site.
